## 👋 About me

I'm an **AI & Data Engineer** who turns legacy data into governed, AI-ready platforms.
I've spent 15+ years between business and IT — insurance and reinsurance, finance and commercial domains — and today I build:

- **Data platforms** — migrations from on-premises SQL Server to the cloud, CDC ingestion, **Data Vault 2.0**, **medallion lakehouses**, streaming with **Kafka / Event Hubs**.
- **GenAI applications** — **RAG** assistants, knowledge mining, agents and LLM evaluation, with security and Responsible AI controls built in.
- **The plumbing that makes both reliable** — config-driven pipelines, data quality checks, reconciliation, CI/CD and infrastructure as code.

I work **architecture first**: a small working slice end to end, proven by checks, then scale.
